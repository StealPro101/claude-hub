Join in

  1. Get a free GitHub account — github.com/signup.
  2. Open the join link a friend sent you. It ends in /join?code=….
  3. Press Sign in with GitHub. GitHub only asks “is this you”; nothing can be written to your account and your token is never kept.

Sign in with GitHub

Then add a game

  • A game is one index.html in a public repo on your own GitHub, with Pages switched on and the topic claude-hub-game.
  • Your project is public on GitHub — that is how it is found. Here it stays private until you publish it.
  • New games arrive as drafts: set a name, a description and a cover picture, then publish.
  • Up to twenty games each.
