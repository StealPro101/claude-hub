Claude Hub

Join the Hub

Three steps, no password to invent, nothing to install.

  1. Get a free GitHub account — github.com/signup. Any name you like.
  2. Open the join link a friend sent you. It ends in /join?code=… — you are on it now if the line under the button says so.
  3. Press Sign in with GitHub. GitHub only asks “is this you”. The Hub gets your name and picture and nothing else, and can never write anything to your account.

Sign in with GitHub

Then add a game

A game is one index.html in a repo on your own GitHub, with Pages switched on and the topic claude-hub-game. The Hub plays it from https://<your-login>.github.io/<repo>/ — an address it works out itself, so nobody can put a game here that is not on their own account.

  • Your project is public on GitHub — that is how the Hub finds it. On the Hub it stays private until you publish it.
  • New games arrive as drafts. Only you see them until you set the name, description and picture and press Publish.
  • Up to twenty games each.
