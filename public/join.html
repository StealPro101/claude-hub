JOIN THE HUB

▸ three steps ◂

GET IN

  1. Get a free GitHub account — github.com/signup. Any name you like.
  2. Open the join link your friend sent you (it ends in /join?code=…). You are on it now if the button below says you are.
  3. Press Sign in with GitHub. GitHub asks nothing but “is this you” — the Hub gets your name and picture, nothing else.

🔑 SIGN IN WITH GITHUB

ADD A GAME

Your game lives in a repo on your own GitHub, with GitHub Pages on and the topic claude-hub-game. The Hub plays it from https://<your-login>.github.io/<repo>/ — so nobody can put a game on the Hub that is not on their own account.

By hand: make the repo, turn Pages on, add the topic. Then it shows up within 15 minutes, or press Add on your MY GAMES page.
