# CLAUDE HUB 🕹️

The crew's shared arcade. Every round has a category — everyone builds a game with
their Claude, uploads it here, best game wins.

**Play:** https://StealPro101.github.io/claude-hub/

**Upload:** paste [UPLOAD.md](UPLOAD.md) (plus the upload token from the group chat)
to your Claude and say "upload my game". Manual fallback: the [submit page](https://StealPro101.github.io/claude-hub/submit.html).

**Rules:** one folder per game under `games/`, only touch your own folder,
game = one self-contained `index.html` + `info.json` (title / author / category).
